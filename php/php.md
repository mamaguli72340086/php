## Extensiones recomendadas para PHP en VS Code

Para mejorar la experiencia de desarrollo en VS Code, instala las siguientes extensiones:

1. **PHP Intelephense** ([Enlace](#)) Proporciona autocompletado inteligente, referencias y análisis de código.
2. **PHP Debug** ([Enlace](#)) Permite depuración paso a paso con Xdebug.
3. **PHP Namespace Resolver** ([Enlace](#)) Puede importar y expandir tu clase. También puedes ordenar las clases importadas por longitud de línea o en orden alfabético.
4. **Trailing Spaces** ([Enlace](#)) Resalte los espacios finales y elimínelos en un abrir y cerrar de ojos
5. **Andromeda** ([Enlace](#)) Tema instalado
6. **Auto Rename Tag** ([Enlace](#)) Cambie automáticamente el nombre de la etiqueta HTML/XML emparejada
7. **Docker** ([Enlace](#)) La extensión de Docker facilita la compilación, administración e implementación de aplicaciones en contenedores.
